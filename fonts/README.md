# فونت وزیرمتن (Vazirmatn)

فایل `Vazirmatn[wght].woff2` را از https://github.com/rastikerdar/vazirmatn (پوشه‌ی `fonts/variable/`) دانلود کنید
و دقیقاً با همین نام در این پوشه قرار دهید. سپس `npm run copy` را اجرا کنید.
اگر فایل نبود، برنامه با فونت‌های سیستم (Noto Sans Arabic / Tahoma) کار می‌کند.
